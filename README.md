# ИИ-Департамент маркетинга

Публичная HTML-страница: крупный заголовок департамента, CTA «ФОТ людей против затрат на ИИ», схема взаимодействия
«от задачи до результата» и модели департамента. Карточки-тезисы, навигация, поиск и
таблицы отделов сняты 20.11.2026. В схеме модель каждой должности показана цветной плашкой
в цвете компании-разработчика. Легенды цветов над схемой нет: её сняли по просьбе владельца.

Размещается бесплатно на GitHub Pages. Внешние шрифты и библиотеки не требуются.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | Вся страница: вёрстка, встроенные шрифты (data-URI) и данные отдела в скрипте — `MN` (названия моделей), `MV` (компании), `VC` (цвет компании: плашки на схеме и рейтинг), `DEPTS` (отделы, должности, цепочки моделей `ch`) |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть, без Jekyll |

Публикуется ветка `main`, корень `/`: https://rumarketolog.github.io/marketing-department-site/

## Важно знать

- 🔴 **Модели на странице с 14.10.2026 намеренно расходятся с конфигурацией отдела**
  (`roles.toml` / `models.toml` в приватном репозитории). Актуальные названия
  для публичной страницы задаются в `MN` в файле `index.html`.
- 🟡 Первая модель в массиве `ch` — основная, её страница подсвечивает и выводит
  на схеме; рейтинг моделей и счётчики «N моделей · N сотрудников департамента» считаются из тех же
  массивов автоматически.
- 🟢 **Яндекс Метрика:** счётчик `113625002` (аккаунт `rumarketolog@yandex.ru`) —
  скрипт перед `</head>`, `<noscript>` сразу после `<body>`. Вебвизор, карта кликов,
  внешние ссылки, точный показатель отказов. Проверка: открыть страницу с
  `?_ym_debug=1` — в консоли `PageView. Counter 113625002`.
