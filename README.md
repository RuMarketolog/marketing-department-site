# Департамент маркетинга

Публичная HTML-страница: структура отдела, должности, модели и схема взаимодействия.

Размещается бесплатно на GitHub Pages. Внешние шрифты и библиотеки не требуются.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | Вся страница: вёрстка, встроенные шрифты (data-URI) и данные отдела в скрипте — `MN` (названия моделей), `DEPTS` (отделы, должности, цепочки моделей `ch`), `MV` (компании) |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть, без Jekyll |

Публикуется ветка `main`, корень `/`: https://rumarketolog.github.io/marketing-department-site/

## Важно знать

- 🔴 **Модели на странице с 14.10.2026 намеренно расходятся с конфигурацией отдела**
  (`roles.toml` / `models.toml` в приватном репозитории). По решению владельца
  обновлена только эта страница: руководитель — Claude Fable 5.1, заместитель —
  GPT-6 Astra, Gemini 3.1 Pro заменён на Gemini 4 Argon и стоит первым в цепочках
  восьми должностей. Не «чинить» обратно по `roles.toml` без слова владельца.
- 🟡 Первая модель в массиве `ch` — основная, её страница подсвечивает и выводит
  на схеме; рейтинг моделей и счётчики «N моделей · N компаний» считаются из тех же
  массивов автоматически.
- 🟢 **Яндекс Метрика:** счётчик `113625002` (аккаунт `rumarketolog@yandex.ru`) —
  скрипт перед `</head>`, `<noscript>` сразу после `<body>`. Вебвизор, карта кликов,
  внешние ссылки, точный показатель отказов. Проверка: открыть страницу с
  `?_ym_debug=1` — в консоли `PageView. Counter 113625002`.
