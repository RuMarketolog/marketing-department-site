# ИИ-Департамент маркетинга — порядок работы

Оперативный контекст и грабли — в `CLAUDE.md`. При расхождении прав `CLAUDE.md`.

## Порядок правки

1. Склонировать репозиторий заново: локальной рабочей копии в `D:\ИИ` нет.
2. Найти место правки через `grep -n`. Целиком `index.html` не читать: в нём встроенные шрифты.
3. Внести правку. Цвета — через токены во всех трёх темах. Тексты и цифры — дословно
   от владельца. Если правка меняет производное значение (кратность, ширину полосы),
   пересчитать его и сказать владельцу.
4. Проверить в headless Chrome (см. `CLAUDE.md`).
5. Дописать строку в таблицу «История» в `README.md`: что изменилось и почему.
6. Коммит с осмысленным сообщением по-русски → `git push origin main` (без `--force`).
7. Дождаться сборки GitHub Pages и проверить живую страницу по уникальной строке правки.

## Что считать готовым

| Проверка | Как |
|---|---|
| Светлая и тёмная тема | скриншоты 1280px; тёмная — через `data-theme="dark"` |
| Телефон | iframe шириной 390px: нет горизонтальной прокрутки, переносы ровные |
| Ошибок JS нет | `--dump-dom` + `--enable-logging=stderr`, нет `Uncaught` |
| Анимации | работают; при `prefers-reduced-motion` выключены |
| История | строка в `README.md` |
| Опубликовано | `git status -sb` без `ahead`, живая страница отдаёт новую версию |

## Чего не делать

- 🔴 Не публиковать на странице цифры, которых не давал владелец.
- 🔴 Не трогать счётчик Яндекс Метрики `113625002` в `<head>` и `<noscript>`.
- 🟡 Не возвращать снятые блоки (тезисы, навигацию, поиск, таблицы отделов) без просьбы
  владельца. Данные `DEPTS` на месте: из них строятся схема и рейтинг.
