## Цвета и токены

- 🔴 **Каждый цветовой токен живёт в трёх местах:** `:root` (светлая тема),
  `@media (prefers-color-scheme: dark){:root:not([data-theme="light"])…}` и `:root[data-theme="dark"]`.
  Правка в одном месте даёт разные цвета в разных темах.
- 🟡 Цвет плашки модели на схеме и аватара в рейтинге — одна карта `VC` (компания → токен отдела).
  `MV` и `VC` объявлены рядом с `MN`, до схемы: `node()` рисует плашку сразу.
- 🟡 Белый текст на `#E8590C` даёт контраст 3,6 — мало для мелкого текста. Для кнопок с белым
  текстом брать более тёмный оранжевый (градиент до `#D4500A`), для мелких оранжевых подписей
  на светлом фоне — `--cta-acc-ink` (`#B0400A`).

## Проверка в headless Chrome

- 🟡 **Окно уже 500px headless не даёт.** `--window-size=390,…` молча рисует 500px, и скриншот
  выглядит обрезанным справа. Телефон проверять страницей-обёрткой с `<iframe style="width:390px">`.
- 🟡 **Анимации ловятся ненадёжно.** Кадр по `--virtual-time-budget` не гарантирует, что блик
  `ctaShine` будет в кадре. Для проверки заморозить его: `animation-play-state:paused`
  и отрицательная `animation-delay`. Для сравнения «до/после» выключать анимации целиком.
- 🟢 **Чистку CSS проверять сравнением снимков.** Снять страницу до и после правки
  (светлая, тёмная, 390px, анимации выключены) и сравнить файлы через `cmp`.
  21.11.2026 так подтвердили удаление 98 строк.
- 🟡 Ошибки JS: `chrome --headless=new --enable-logging=stderr --v=0 --dump-dom <файл>`,
  в stderr искать `Uncaught`. Строки `external_registry_loader_win` — шум Chrome.

## Публикация

- 🟡 `git push` на GitHub иногда висит по 5 минут и падает с `Connection timed out`. Коммит при этом
  остаётся локально. Проверить `git ls-remote origin refs/heads/main` и повторить push с `timeout 90`.
- 🟢 Живую версию проверять `curl` с параметром-антикэшем (`?r=$RANDOM`) по уникальной строке
  из правки: GitHub Pages отдаёт старую версию, пока идёт сборка.
